# AI Virtual Mouse Using Hand Gestures

This project uses computer vision and hand tracking to control the mouse cursor through hand gestures, without requiring a physical mouse.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Features
- Hand tracking using a webcam
- Cursor movement using finger gestures
- Gesture-based mouse clicking
- Real-time interaction

## How to Run
1. Install Python and ensure your webcam is connected.
2. Install the dependencies: `pip install -r requirements.txt`
3. Run: `python hand_tracking.py`

Replace `hand_tracking.py` with your actual entry-point filename if different.
